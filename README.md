# Portfolio Landing Page

Professional portfolio and landing page focused on Web Design services for SaaS, Fintech and E-commerce.

This project includes a modern responsive landing page and a secure Node.js backend to handle the contact form.

## Features

- Modern and responsive landing page design
- Service packages presentation (Landing Start, Conversion and Enterprise)
- Case studies section
- Contact form with backend integration
- Security best practices (Helmet, CORS, input sanitization)
- Email sending via Resend API

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- Helmet
- CORS
- Dotenv
- Resend API

## Project Structure

- `index.html` — Main landing page
- `server.js` — Express server and contact form API
- `package.json` — Project dependencies and scripts
- `.env.example` — Environment variables template
- `.gitignore` — Git ignore rules
